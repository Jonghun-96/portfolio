👋 Hello.

안녕하세요.
프론트엔드 개발자로 성장하고 있는 김종훈입니다.

이 프로젝트는 HTML, CSS, JavaScript를 기반으로 제작한 개인 포트폴리오 사이트입니다.
디자인 전공 경험을 바탕으로 UI 완성도와 사용자 흐름을 함께 고려하며 구현했습니다.

🛠 Tech Stack

HTML5

CSS3 (Flexbox, Grid, 반응형 레이아웃)

JavaScript (ES6+)

💡 구현 내용

반응형 웹 레이아웃 설계

JavaScript 기반 인터랙션 구현

스크롤 이벤트 및 동적 UI 처리

시맨틱 마크업 및 구조적인 DOM 설계

유지보수를 고려한 CSS 구조화

🎯 프로젝트 목표

단순한 퍼블리싱을 넘어, 동적인 사용자 경험을 구현하는 프론트엔드 역량 강화

예측 가능한 구조와 깔끔한 코드 작성

디자인과 기능을 연결하는 개발 능력 확장

🚀 Next Step

현재는 React와 TypeScript 기반 프로젝트를 통해
컴포넌트 설계와 상태 관리 학습을 확장하고 있습니다.
